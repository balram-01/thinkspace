# thinkspace

A high-performance native workspace engine for React Native, designed for document-centric apps with infinite canvas, PDF rendering, annotations, selection, gestures, and handwriting.

## Installation


```sh
npm install thinkspace
```


## Usage


```js
import { ThinkspaceView } from "thinkspace";

// ...

<ThinkspaceView color="tomato" />
```
